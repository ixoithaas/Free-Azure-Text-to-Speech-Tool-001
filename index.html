Give your words a voice.

Cadence turns scripts into natural-sounding narration with Microsoft neural voices. Fine-tune delivery, preview your audio, and export a polished clip.

ⓘ

About this GitHub Pages site: Pages can host static files, but the Cadence studio needs a Node.js server for speech synthesis and a PostgreSQL database for saved clips. This page is the project landing page; it cannot run the full studio by itself.

Run the full app

Deploy the Next.js app on a server host

The interactive studio uses Next.js API routes and PostgreSQL, which GitHub Pages does not execute. To use all features, deploy this repository to a host that supports Node.js, configure DATABASE_URL, and follow the setup instructions in the repository. Use GitHub Pages for this static project page, or update the app link above once you have deployed the studio.
